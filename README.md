Неофициальный клиент шахматного сервера lichess.org для устаревшой ОС Windows 10 Mobile.  
Написан с нуля, из готового только использование [Lichess API](https://lichess.org/api)

Выражаю огромную благодарность автору статьи https://habr.com/ru/articles/682122/, по сути весь код Lichess/Bitboards/ нагло скопирован оттуда.

И, да, это мой первый крупный проект в жизни!
